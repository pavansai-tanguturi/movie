# Cinephile 🎬

A minimal movie browser and favorites app built with [Next.js](https://nextjs.org) and the OMDb API.

Live Demo: [movie-cinephile.vercel.app](https://movie-cinephile.vercel.app/)

---

## Features

- 🔍 Search movies by title
- 📄 View detailed movie info
- ❤️ Add/remove favorites (saved in your browser)
- ⚡ Fast, responsive UI (Tailwind CSS)
- Built with Next.js 14 (App Router)
